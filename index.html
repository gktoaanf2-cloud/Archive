🌐 전시관 공유 가이드 (Netlify Drop)
다른 사람에게 완성된 이 페이지를 '링크'로 보여주고 싶다면?

1. 우측 상단의 [HTML 전시관 내보내기] 버튼을 누릅니다.
2. 다운로드된 HTML 파일은 타인이 수정할 수 없는 관람 전용 회지입니다.
3. 인터넷 창을 열고 [ app.netlify.com/drop ] 에 접속합니다.
4. 다운받은 HTML 파일을 중앙 원 안으로 드래그 앤 드롭합니다.
5. 3초 뒤 초록색 링크가 생성됩니다. 그 링크를 앤오님께 공유하세요!
